# 冒险岛怀旧服国服 · 自动练级工具

> **这个文件是给「只想用、不想碰代码」的人看的。**
> 想看源码、自己改、自己打包 —— 看 [README.md](README.md)。

一个帮你自动打怪的挂机工具。它**不读游戏内存、不改游戏文件**，做法跟人一样：看游戏画面 → 认出怪和自己在哪 → 按键盘。

---

## 一、先下载

**去 [Releases 页面](../../releases/latest) 下载**，有两种，按自己情况挑一个：

| 我是什么情况 | 下哪个 | 多大 |
|---|---|---|
| 第一次用 | `MapleStoryAutoLevelUp-CN-v1.0.3.zip` | 约 106 MB |
| 已经装过旧版（v1.0 / v1.0.1 / v1.0.2） | `patch-to-v1.0.3-universal.zip` | 约 6 MB |

### 第一次装：完整包

1. 下载后**解压整个文件夹**（右键 → 解压到当前位置）；
2. 进文件夹，**右键 `冒险岛自动练级.exe` → 以管理员身份运行**。

> ⚠️ **不要只把 exe 拿出来用**。它需要旁边的文件夹才能跑，必须整个文件夹一起解压。
>
> ⚠️ **建议一开始就用管理员身份运行**。游戏客户端通常是管理员权限启动的，
> 普通权限的程序**收不到游戏里按的键**（Windows 的机制），表现就是「录路线时角色不动」。
> 想省事可以右键 exe → 属性 → 兼容性 → 勾上「以管理员身份运行此程序」。

### 升级：老用户打补丁

1. 先**关掉**冒险岛自动练级程序；
2. 把补丁 zip 解压到**任意位置**（解压本身不会动你的程序）；
3. 双击里面的 `应用补丁.bat`，按提示回车。

脚本会自己找到程序目录（找不到会问你路径），先把要替换的文件备份到 `_backup_补丁前` 文件夹，再覆盖。

**你的配置、地图路线、怪物模板都不会被碰。** 万一出问题，把备份文件夹里的东西复制回程序目录就还原了。

## 二、第一次用要做准备

工具是「看画面」干活的，所以它得先认识**你的角色**和**你要打的图**。装完是空的，要自己做一遍。

**开始前先确认两件事：**

- 游戏要开**窗口模式**（不能全屏）；
- 游戏左上角的**小地图要打开**（工具靠它判断你在哪）。

**然后按这 4 步做：**

### 第 1 步：让工具认识你的角色（F2）

在主界面按 `F2`：

1. 弹出的框里填**你角色的名字**（要和游戏里显示的完全一样），点确定；
2. 然后游戏画面上会出现框选提示 —— 用鼠标**框住角色的名字**那一行，再**点一下角色中心**。

> 只有换角色才需要重做。不标的话，工具找不到你在哪，走位会乱。

### 第 2 步：教它走一条路线（F4）

在主界面按 `F4`，给这张图起个名字（中文就行，比如「蘑菇村」）。

会弹出一个置顶的小面板，**全程用鼠标点按钮**：

1. 让角色**站到路线的起点**，点【开始录（我站好了）】；
2. 一路走到平台另一头，点【在这折返，存下这段】；
3. 再走回起点附近，点【这是终点，保存这段】；
4. 点【主线录完了，下一步】。

> ⚠️ **去程和回程一定要分成两段**。挤在一段里的话，同一个位置既有向左又有向右的记录，角色会一路冲出平台。
>
> **这一步也会把地图创建出来** —— 后面第 3 步要在列表里选它。

### 第 3 步：选中这张图

关掉界面，重新打开 —— 刚录的图会出现在下方的地图列表里，**点它选中**。

### 第 4 步：告诉它打哪种怪（F3）

按 `F3`，用鼠标**框住一只怪**，工具会自动抠图存档。

- 一只怪**截 2 个姿态就够**（比如站着 / 攻击时），挑差别大的两种；
- 游戏是横版，怪只有左右两个朝向，工具会**自动镜像**，所以不用自己截反面；
- 感觉漏怪 / 打空 → 多截几个姿态；
- 感觉变卡了 → 用「模板查重」清理重复的。

## 三、开始挂机

准备做完，按 `Start` 或 `F1` 就开始自动打怪了。

**界面上的快捷键：**

| 键 | 干什么 |
|---|---|
| `F1` | 开始 / 暂停 |
| `F2` | 标定角色名字（换角色才用） |
| `F3` | 截怪物模板（换图才用） |
| `F4` | 录挂机路线 |

关掉界面直接点窗口右上角的 × 即可。

**挂机时注意：**

- 游戏窗口要**一直开着**，别最小化（挡住了没关系，最小化不行）；
- 界面**「工具箱」页签里有完整的图文教程**，忘了怎么操作可以随时翻。

## 四、遇到问题

### 点 F2 / F3 / F4 没反应

**多半是没用管理员身份运行。**

这个工具用内核级驱动给游戏发按键、也要在录路线时读你在游戏里按了什么 —— 这两件事都**必须管理员权限**，否则 Windows 会静默拦掉（不报错，就是没反应）。

→ 关掉程序，右键 `冒险岛自动练级.exe` →「以管理员身份运行」。

> 想一劳永逸：右键 exe → 属性 → 兼容性 → 勾上「以管理员身份运行此程序」。

### 按 F4 后卡住 / 提示「抓不到游戏画面」

工具要按固定尺寸去看游戏画面。**窗口大小对不上，就一帧都拿不到。**

按 `F4` 时如果尺寸不对，会直接弹窗告诉你差多少，并给一个按钮：

> **「一键按当前窗口大小改配置（推荐）」**

点它就自动改好了，然后继续录制流程。不用手动算尺寸。

> 如果游戏窗口之后又改了大小，重新点一次这个按钮即可。
>
> 老版本只会笼统提示「请检查窗口是否被挡住或最小化」，容易让人以为是双屏或焦点问题 —— 其实和那些无关。

### 界面打不开 / 一闪就没了

程序几乎没有「闪一下就消失」的情况（它是图形界面，正常会停在窗口上）。真遇到的话，按顺序试：

1. **确认是解压后再双击的**。直接在压缩包里双击 exe、或者只把 exe 单独拖出来，都会打不开 —— 它需要旁边的文件夹；
2. 检查杀毒软件是否拦截了（这类工具常被误报），把它加进信任列表；
3. 打开程序文件夹里的 **`log`** 目录，看有没有当天的 `.log` 文件，把里面的内容发给作者。

> 如果你是**从源码运行**（自己装了 Python），可以用 `诊断启动.bat` 带黑窗口启动看报错 —— 免安装包里没有这个文件。

### 角色不走 / 走一下就停

按顺序检查：

1. 游戏窗口是不是**前台**（被别的窗口盖住、或者最小化了都不行）；
2. 是不是没勾对地图 —— 主界面下方列表里**选中**要挂的那张图；
3. 怪物模板是不是没截（第 4 步）。

### 还是不行

在程序的 `log` 文件夹里找最新的那个 `.log` 文件，连同你的操作步骤一起发给作者，这样定位最快。
